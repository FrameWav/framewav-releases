# Framewav — Windows releases

Framewav turns 3–10 clips into several finished 1080×1920 edits in 10 styles.
Your clips never leave your computer.

Official site: https://framewav.com

## Download
Get the latest Windows installer from the Releases page (right side of this page).
Each release lists its SHA-256 checksum so you can verify the file.

## Windows SmartScreen
The installer is not yet code-signed, so Windows may show a warning.
Click "More info" → "Run anyway".
